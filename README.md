# neverloseawebsite

A Chrome extension that saves any website in one tap with a note and tags, sorts it into folders, and helps you find it again in seconds. Everything stays on your device.

Website: https://neverloseawebsite.me

## Install (about 1 minute)

1. Download this repo: Code, then Download ZIP. Unzip it.
2. In Chrome, open `chrome://extensions` and turn on Developer mode.
3. Click Load unpacked and choose the unzipped folder that contains `manifest.json`.
4. Pin the extension from the puzzle piece menu.

## Use it

1. Open any website and click the extension icon (or press Ctrl/Cmd + Shift + S).
2. Tap Lock in Memory, then pick or make a folder.
3. Click Search my saved websites to find it later.
